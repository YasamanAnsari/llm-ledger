03 / THE METHODOLOGY

A date is only as useful
as its evidence.

The ledger keeps the milestone and its source together, so you can choose, filter, and audit the dates behind your analysis.

Read the full methodology ↗
01 One model. Distinct milestones.

Announcement, API access, downloadable weights, consumer rollout, and retirement are separate events. For adoption studies, pick the event that matches the population you study.

The headline date uses the earliest global API availability, weights release, or consumer rollout. If those are missing, it falls back to API preview or free-tier access, then a third-party platform listing. The timeline shows which event supplied it.

02 Confidence you can inspect.

Verified: primary-source curation, independent sources agreeing within two days, or a platform reporting its own event. Inferred: a single source or unresolved differences of 3–30 days. Disputed: stated dates differ by more than 30 days, with all values preserved.

A platform’s own record takes precedence over third-party copies. Repository creation timestamps are bounds and do not verify a launch by themselves. Inspect the source and verifier on each event.

03 Precision stays honest.

A month is displayed as a month, never as an invented day. Year and quarter placeholders do not set first public availability. Timestamp dates use UTC; dates read from a page follow the printed date.

Future retirement dates are schedules, not completed shutdowns. Platform-specific retirements apply only to that host. Changed source dates remain in claim history and the reschedules export.

04 Clear scope. Reproducible results.

The unit is a named trained checkpoint from a lab. Base and instruct checkpoints can be separate models. Packaging variants, ordinary quantizations, API aliases, adapters, and community merges are generally excluded.

The repository publishes the pipeline, schema, cross-catalog names, and validation rules. This website is rebuilt from the repository after every daily update. Scale, compute, and other Epoch AI columns are available in the enriched download.
